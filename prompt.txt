CÁC TAB CHỨC NĂNG (5 tab)
══════════════════════════════════════════

📚 TAB 1: DANH MỤC TÀI NGUYÊN
- Bảng hiển thị: STT, Ảnh, Mã, Tên, Nhóm, Loại, ĐVT, Tổng SL, Còn lại, Vị trí kho, Trạng thái
- Tìm kiếm full-text theo tên/mã
- Lọc theo nhóm: Sách thư viện / Thiết bị / Tài liệu tham khảo
- Lọc theo loại (ví dụ: SGK, Sách tham khảo, Máy chiếu, Loa...)
- Phân trang (10 item/trang)
- Nút "Mượn" trên mỗi hàng → mở form đăng ký mượn
- Form mượn: Họ tên, Loại (GV/HS), Đơn vị, SĐT, Ngày mượn, Hạn trả, Số lượng, Mục đích, Ghi chú
- Mã phiếu tự động: PM + timestamp

📋 TAB 2: DANH SÁCH PHIẾU MƯỢN
- Bảng: Mã phiếu, Người mượn, Tài nguyên, Ngày mượn, Hạn trả, Trạng thái, Hành động
- Trạng thái badge màu: Chờ duyệt (vàng), Đã duyệt (xanh), Đã trả (slate), Quá hạn (đỏ), Từ chối (hồng)
- Lọc theo trạng thái
- Tìm kiếm theo mã phiếu, tên người mượn
- Thủ thư: Nút Duyệt ✅, Từ chối ❌, Nhận trả ↩, Xóa 🗑️
- Khi duyệt: giảm số lượng kho; Khi trả: hoàn số lượng kho
- Khi xóa phiếu chưa trả: tự động hoàn số lượng kho
- Badge đếm phiếu "Chờ duyệt" trên tab

📊 TAB 3: BÁO CÁO & THỐNG KÊ (Dashboard)
- 5 KPI cards: Tổng tài nguyên, Đang cho mượn, Chờ duyệt, Quá hạn, Hoàn thành
- Top 5 tài nguyên được mượn nhiều nhất (thanh progress bar)
- Phân bố theo nhóm: Thiết bị / Sách / Tài liệu
- Phân bố người mượn: Giáo viên / Học sinh
- Cảnh báo phiếu quá hạn (thông tin liên hệ, nút xem/xóa phiếu)
- Nút In báo cáo
- Nút Xuất CSV
- Thủ thư: Nút "Reset thống kê về 0" (xóa hết phiếu + reset borrowCount)

🔧 TAB 4: QUẢN TRỊ KHO (Chỉ Thủ thư)

  + Tổng số lượng, Số lượng còn, Vị trí kho, Trạng thái

- Tìm kiếm trong bảng quản trị

ℹ️ TAB 5: GIỚI THIỆU

FIREBASE CẤU HÌNH
══════════════════════════════════════════
- Authentication: Bật Google Sign-In + Email/Password
- Firestore Collections:
  + users: {uid, email, displayName, role, createdAt}
  + resources: {id, code, name, group, type, unit, totalQty, availableQty, location, status, imageUrl, borrowCount}
  + tickets: {id, ticketCode, borrowerName, borrowerType, department, phone, resourceId, resourceTitle, quantity, borrowDate, dueDate, purpose, notes, status, createdAt}
- Real-time sync: Sử dụng onSnapshot() để đồng bộ tức thì giữa bạn đọc và thủ thư
- Auto admin: Khi email đăng ký trùng email admin → tự động set role = "librarian"
- Fallback: Nếu chưa cấu hình Firebase → dùng localStorage

══════════════════════════════════════════
FIRESTORE RULES (không hết hạn)
══════════════════════════════════════════
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
    match /resources/{resourceId} {
      allow read: if request.auth != null;
      allow write, delete: if request.auth != null;
    }
    match /tickets/{ticketId} {
      allow read: if request.auth != null;
      allow create, update, delete: if request.auth != null;
    }
  }
}
